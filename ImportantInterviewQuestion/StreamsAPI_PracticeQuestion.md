Here are some **coding problems** focused on **streams**, **reduce()**, and **lambda expressions** in Java:

---

### **Questions:**

1. **Sum of Even Numbers**  
   Given a list of integers, calculate the sum of all even numbers using the `reduce()` method.

2. **Find the Longest String**  
   Given a list of strings, find the longest string using `reduce()`.

3. **Count Strings That Start with a Specific Letter**  
   Given a list of strings and a character, count how many strings start with that character using streams and lambda expressions.

4. **Product of Numbers**  
   Calculate the product of all numbers in a list using the `reduce()` method.

5. **Find Maximum Value**  
   Find the maximum value in a list of integers using the `reduce()` method.

6. **Concatenate Strings**  
   Given a list of strings, concatenate all of them into a single string separated by commas using streams.

7. **Filter and Square Numbers**  
   Filter out odd numbers from a list of integers, then calculate the sum of the squares of the remaining numbers.

8. **Group Strings by Length**  
   Group strings in a list by their length using streams and collectors.

9. **Find the First Non-Empty String**  
   Given a list of strings, find the first non-empty string using streams.

10. **Reverse List Using Reduce**  
    Reverse a list of integers using the `reduce()` method.  
    Hint: You will need to work with a mutable list or string builder.

---

### **Bonus Questions:**

11. **Count Distinct Words**  
    Given a list of strings, count the number of distinct words.

12. **Check Palindrome Strings**  
    Given a list of strings, check if all strings in the list are palindromes using streams.

13. **Calculate Average Length of Strings**  
    Calculate the average length of all strings in a list using streams.

14. **Find Frequency of Words**  
    Given a list of words, create a map of word frequencies using streams.

15. **Partition Numbers into Even and Odd**  
    Partition a list of integers into two lists: one containing even numbers and the other containing odd numbers.
